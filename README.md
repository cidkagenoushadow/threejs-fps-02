A round-based tactical FPS in a container yard at dusk. Five attackers against five defenders, a bomb to plant at site A or B, money between rounds to buy rifles, SMGs and grenades, and bots that route through the map, hold positions, and react to what they see and hear.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. WASD to move, mouse to look, click to fire, R to reload, 1/2/3 to swap weapons, G to throw a grenade, hold E to plant the bomb, B for the buy menu, Ctrl to crouch, Space to jump.

Built with three.js 0.187.0, no build step, no network. Made for [make.fun](https://make.fun).
